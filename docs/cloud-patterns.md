# Паттерны облака

## Паттерн_1 (текущий, v22.7)

| параметр | значение |
|---|---|
| радиус сферы | `min(w,h) * (expanded ? 1.02 : 0.82)` |
| радиус внутренней сферы | `radius * (expanded ? 0.66 : 0.60)` |
| внешняя сфера (поле Старшего) | вращение `-yaw*0.45 - spin*0.55`, шрифт `0.034 + 0.052*depth` |
| внутренние теги | шрифт `0.055 + 0.075*depth` |
| цвет поля | янтарь `#F2A93B` |
| цвет слов Младшего | циан `#3FC6DC` |
| цвет в триангуляции | беж `#E8E0D2` |
| линии созвездия | `#E8E0D2`, альфа `0.12 + 0.26*depth`, 2 ближайших соседа |
| туманность | кеш в битмап, пересборка при 1.6°, 2 фоновых облака |
| свечение тегов | живое, каждый кадр, радиус `0.18 + 0.14*depth` |
| автовращение | 38 с на оборот |
| бросок | чувствительность 0.38, потолок 1800, гашение 0.85 |
| глубина резкости | BlurMaskFilter 1..5 px при depth < 0.55 |
| звук касаний | фронт (z > 0.72) и тыл (z < −0.72) |

## Паттерн_2 (с 23.4, перед экспериментами)

То же, что Паттерн_1, плюс:

| изменение | значение |
|---|---|
| звук касаний | пентатоника A C D E G, угол задаёт октаву (1.0 / 2.0 / 0.5 / 1.5) |
| хвост удара | 0.22 с, затухание exp(−11t) |
| вибрация | 5-14 мс на касание, 22 мс на переворот |
| глитч-звук | отсутствует |

Откат: вернуть из таблицы Паттерн_1 и убрать пентатонику в `SoundEngine.bell`.

## Паттерн_3 (с 25.1)

Наследует Паттерн_1/2 плюс:

| изменение | значение |
|---|---|
| перелив каналов | цикл 6.4 с, линейная кривая |
| передний план | порядок отрисовки едет вместе со сдвигом цветов |
| контраст слоёв (вероятности нулевые) | 100% / 55% / 38% |
| звук облака | 12 дорожек, 3 ступени на угол, октавы 1.0 / 2.0 / 1.5 / 3.0 |
| удар | негармонические партиалы 1 / 2 / 2.42 / 3.01 / 4.16 / 5.43, без шумовой атаки |

## Паттерн_3 — звук облака (25.2)

| параметр | значение |
|---|---|
| дорожки | 12 статических (4 угла × 3 ступени) — лимит AudioTrack не превышен |
| ступени | 1.0 / 1.2 / 1.5 — ля-минорный аккорд A–C–E |
| октавы углов | 1.0 / 2.0 / 1.5 / 3.0 (все — тоны того же аккорда) |
| база | 330 Гц |
| тембр | негармонические партиалы 1 / 2 / 2.42 / 3.01 / 4.16 / 5.43 |
| затухание | 2.4 + 1.6·k |
| атака | шум 0.05 со спадом 220/с (почти без «тука») |
| эхо | задержки 31 и 67 мс, обратная связь 0.30 и 0.18 |
| панорама | 0.35/0.65, 0.65/0.35, 0.45/0.55, 0.55/0.45 по углам |
| громкость | 0.22 + 0.70·(скорость/1600), снаружи ×0.55 |
