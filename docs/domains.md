# Домены Старших арканов

Домен — рамка, в которой читаются Младшие карты в режиме пары.
Слово берётся из «Divinatory Meanings» Уэйта; там, где не берётся, помечено.

## Отступления от буквы Уэйта

Четыре: **Иерофант, Влюблённые, Дьявол, Звезда**.
Во всех случаях меняется только рамка чтения; исходные слова Уэйта остаются в тегах карты.
